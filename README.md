Task Tracker
A simple task management web app built with ASP.NET Core MVC.

Features
- Add, edit, and delete tasks
- Track status: Pending, In Progress, Done
- Form validation

Tech Stack
C#, ASP.NET Core MVC (.NET 8), Entity Framework Core, SQL Server, Bootstrap

How to Run
1. Open the project in Visual Studio
2. Run `dotnet ef database update` in the project folder
3. Press F5
